# 🧱 淇淇方块学院 QiqiCraft Academy

专为国内小学二年级小朋友打造的《我的世界》(Minecraft) 主题家庭作业激励应用。小朋友**每完成一小节作业（语文、数学、英语、体育）即可拍照提交**，由 OpenAI 视觉模型化身“方块村长”进行检查、夸奖与温和错题点拨，并掉落**建筑方块、绿宝石、经验球与宠物口粮**！

---

## ✨ 核心功能亮点

1. **📅 作业闯关岛（微习惯“写一点、拍一下”）**
   - 定制二年级四大常驻学科：**语文冒险**、**数学矿洞**、**英语远征**、**体育竞技场**。
   - 体育任务内置 **⏱️ 1分钟跳绳语音倒计时挑战器**。
   - 支持 **iPad 直接拍照 / 相册上传**，并提供 **“✨ 一键生成二年级示例作业图”** 方便随时体验测试。
   - **🔊 中文语音播报**：方块村长自动朗读点评与夸奖，二年级小朋友无需费力认字。

2. **🏰 我的方块世界（真 3D 立体可旋转像素沙盒）**
   - 基于 Three.js 打造的 **3D 像素方块建造沙盒**，支持单指滑动 360° 旋转、缩放、点击放置方块与镐子挖掘回收。
   - 内置 **14 种《我的世界》像素方块**（草方块、橡木、红砖、透明玻璃、樱花树叶、附魔书架、清澈水块、闪耀金块、传奇钻石块、发光萤石、趣味TNT等）。
   - 提供 **📐 建筑蓝图虚影指引**（温馨林间小木屋、钻石守卫瞭望塔、浪漫樱花许愿树）与 **昼夜/黄昏灯光切换（夜晚萤石真实发光）**。

3. **🐾 萌宠乐园（像素宠物领养、喂食与体育活力寻宝）**
   - 5 只像素萌宠：**闪电小狼、橘子喵喵、赤焰小狐、泡泡美西螈、竹林滚滚（大熊猫）**。
   - 使用写作业掉落的骨头、鲜鱼、甜浆果、翠竹、附魔金苹果喂食升级，解锁皇冠形态。
   - **体育打卡联动**：完成跳绳/体育运动可积攒“运动活力值”，消耗活力值派宠物去森林寻宝挖钻石！

4. **🛡️ 英雄换装与村民商店 + 现实心愿单**
   - 史蒂夫风格像素小人换装：解锁并穿戴铁盔、黄金王冠、钻石战甲、附魔钻石剑、引雷三叉戟、苦力怕披风、末地鞘翅。
   - 支持用绿宝石兑换家长设定的 **🎟️ 现实心愿兑换券**（如周末玩30分钟我的世界、去公园、吃冰淇淋等）。

5. **🔐 家长控制台（默认密码：`1234`）**
   - 在 iPad 界面右上角点击 **「家长设置」**（默认密码 `1234`）：
     - 直接配置 **OpenAI API Key / Base URL / 模型名称 (`gpt-4o`)**（未配置 Key 时自动运行高仿真智能村长模式）。
     - 自定义添加/删除每日作业任务、一键开启新一天打卡、手动发放【家长表扬大礼包】。
     - 查看 **📸 历史作业照片墙** 与 AI 批改记录。

## 🚀 启动与 iPad 全屏安装指南

### 1. 启动服务
```bash
npm install
npm run dev
```
- 开发服务器启动后：
  - 本机访问：`http://localhost:5173`
  - **iPad 局域网访问**：确保 iPad 与电脑在同一 Wi-Fi 下，用 iPad Safari 打开 `http://<电脑局域网IP>:5173`

### 2. 在 iPad 上添加为主屏幕全屏 App
1. 用 iPad 的 **Safari 浏览器** 打开上述地址。
2. 点击浏览器顶部的 **「分享」图标**（方框加向上箭头）。
3. 选择 **「添加到主屏幕」(Add to Home Screen)**。
4. 从 iPad 桌面点击 **「方块学堂」** 图标打开，即可享受无地址栏的全屏原生级游戏化体验！
